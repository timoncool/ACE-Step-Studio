Что умеет

Каталог LoRA

131 LoRA с Hugging Face, отобранная по лайкам и скачиваниям, с описаниями и авторами, и поиск по всему Hugging Face — каждый файл проверяется на размер модели до скачивания.

Песня из одной строки

Простая форма: на входе идея, на выходе готовая песня.

Своя LoRA

Песни одного артиста или стиля превращаются в LoRA на вашей видеокарте — тренером HOT-Step по его рецепту LoKR.

Стемы и MIDI

Шесть стемов HT-Demucs; любой трек в многодорожечный MIDI моделью MuScriptor, пианоролл звучит вместе с оригиналом.

Обложка у каждого трека

Трек без своей обложки получает бесплатное фото CC0 с Wikimedia Commons под свой стиль, узор в одном из 21 стиля или обложку, сгенерированную через OpenRouter.

Управление агентом (MCP)

Подключите Claude Code, Claude Desktop или Cursor — агент делает всё, что умеет студия (164 инструмента), видит окно и нажимает кнопки.

Вопросы

Какая нужна видеокарта?

Windows 10/11 x64 и видеокарта NVIDIA с 4 ГБ видеопамяти и больше (GTX 900 и новее). Модели скачиваются из самой студии, когда вы решите.

Рабочий набор — это DiT, планировщик, текстовый энкодер и VAE, всё в GGUF.

Студия сама предложит набор, который потянет ваша видеокарта, но скачивать решаете вы. Каждый файл сверяется по SHA-256 с закреплённой ревизией на Hugging Face, прерванная загрузка докачивается.

Это бесплатно?

Да. Студия бесплатная и с открытым кодом, модели скачиваются бесплатно прямо из неё.

Работает ли без интернета? Уходит ли куда-то моя музыка?

Ваша музыка ваша и остаётся на вашем диске.

  • Без аккаунта — Регистрироваться негде и незачем.
  • Без телеметрии — Студия не сообщает, что вы генерируете.
  • Облако — только по желанию — Ничего не уходит с компьютера, пока вы не добавите ключ, и тогда только для этой возможности.
Можно ли использовать сделанные песни?

Студия, acestep.cpp и ACE-Step 1.5 — MIT. Дообучение Regrind — CC BY-NC-SA 4.0; у каждой LoRA из каталога лицензия её автора.

Можно ли обучить её своему стилю?

Песни одного артиста или стиля превращаются в LoRA на вашей видеокарте — тренером HOT-Step по его рецепту LoKR. Каждую настройку можно поменять, чекпоинт уходит в библиотеку LoRA одним кликом.

Может ли ею управлять ИИ-агент?

Подключите Claude Code, Claude Desktop или Cursor — агент делает всё, что умеет студия (164 инструмента), видит окно и нажимает кнопки. Правила письма ACE-Step идут в комплекте, песни агент пишет сам.

Как она устроена?

Сервис вшит в десктопный exe и следит за C++ движком. Готовые песни импортирует сам сервис, поэтому результат не теряется, даже если окно перезагрузили или закрыли.

React UI ─┐
          ├─ ACE-Step-Studio.exe   (Tauri window + Rust/Axum service)
Rust axum ┘        │
                   └─ acestep.cpp `ace-server`   (C++/GGML, GGUF)
