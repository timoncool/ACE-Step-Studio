功能

LoRA 目录

按点赞和下载量从 Hugging Face 精选的 131 个 LoRA，附描述与作者；还可搜索 Hugging Face 上的全部内容——每个文件下载前都会检查适配的模型尺寸。

一句话生成歌曲

简单模式：输入一个想法，得到一首完整的歌。

自己的 LoRA

同一歌手或风格的歌曲在你的显卡上用 HOT-Step 训练器及其 LoKR 配方变成 LoRA。

分轨与 MIDI

HT-Demucs 分出六轨；用 MuScriptor 把任意歌曲转为多乐器 MIDI，钢琴卷帘与原曲同步播放。

每首曲目都有封面

没有封面的曲目会得到符合其风格的 Wikimedia Commons 免费 CC0 照片、21 种样式之一的图案，或通过 OpenRouter 生成的封面。

由你的智能体驱动（MCP）

连接 Claude Code、Claude Desktop 或 Cursor，智能体就能完成工作室的一切（164 个工具），还能看见并操作窗口。

开始使用

  1. 1安装运行安装程序，或把便携压缩包解压到任意位置。
  2. 2选择模型组首屏会预选显卡能运行的组合，只下载缺少的部分。
  3. 3写作描述和歌词、一个示例，或在简单模式中写一句话。
  4. 4创作引擎自动启动，歌曲进入你的曲库。

常见问题

需要什么显卡？

Windows 10/11 x64，以及 4 GB 或以上显存的 NVIDIA 显卡（GTX 900 或更新）。模型在工作室内由你决定何时下载。

可运行的一组模型包括 DiT、规划器、文本编码器和 VAE，均为 GGUF。

你的显卡模型组下载量
24 GB完整原版 — XL turbo BF16，规划器 4B BF1618.5 GB
13 GB+高质量 — XL turbo Q8_0，规划器 4B Q8_010.1 GB
10 GB+均衡 — XL turbo Q6_K，规划器 1.7B6.7 GB
8 GB+轻量 — XL turbo Q4_K_M，规划器 1.7B5.7 GB
4 GB+最小 — 2B turbo Q4_K_M，规划器 0.6B3.1 GB

工作室会预选你的显卡能运行的模型组，但是否下载始终由你决定。每个文件都按固定的 Hugging Face 版本校验 SHA-256，中断的下载可以续传。

免费吗？

是的。工作室免费且开源，模型也可以在其中免费下载。

没有网络能用吗？我的音乐会被上传吗？

你的音乐属于你，并留在你的磁盘上。

  • 无需账号 — 没有任何需要注册的东西。
  • 无遥测 — 工作室不会报告你生成的内容。
  • 云端需主动开启 — 在你添加密钥之前，没有任何数据离开电脑，且只用于该功能。
生成的歌曲可以使用吗？

工作室、acestep.cpp 与 ACE-Step 1.5 采用 MIT 许可。Regrind 微调为 CC BY-NC-SA 4.0；目录中每个 LoRA 采用其作者的许可。

能用我自己的风格训练吗？

同一歌手或风格的歌曲在你的显卡上用 HOT-Step 训练器及其 LoKR 配方变成 LoRA。每项设置都可修改，检查点一键加入 LoRA 库。

AI 智能体能操作它吗？

连接 Claude Code、Claude Desktop 或 Cursor，智能体就能完成工作室的一切（164 个工具），还能看见并操作窗口。ACE-Step 的写作规则随附，智能体自己写歌。

安装包里有什么？

默认全部本地。云端密钥由你为所选功能添加。

它是如何构建的？

服务编译进桌面程序并管理 C++ 引擎。完成的歌曲由服务自己导入，即使窗口被刷新或关闭，结果也不会丢失。

React UI ─┐
          ├─ ACE-Step-Studio.exe   (Tauri window + Rust/Axum service)
Rust axum ┘        │
                   └─ acestep.cpp `ace-server`   (C++/GGML, GGUF)
